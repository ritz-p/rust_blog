記事は `content/articles/` にMarkdownファイル（`.md`）として置きます。ファイルの先頭に設定を書き、その下に本文を書きます。先頭の設定部分を **フロントマター** と呼びます。

## 記事の基本形

以下をコピーして書き始められます。

````markdown
---
title: "記事のタイトル"
slug: "my-first-post"
created_at: "2026-09-22T12:00:00+09:00"
excerpt: "記事一覧に表示する短い紹介文です。"
tags: ["Rust", "メモ"]
categories: ["開発"]
table_of_contents: true
deleted: false
---

ここに導入文を書きます。

## 最初の見出し

ここに本文を書きます。

```rust
fn main() {
    println!("Hello, world!");
}
```
````

設定はYAML形式で、前後を `---` で囲みます。文字列は `"..."`、複数の値は `["...", "..."]`、オン・オフは引用符なしの `true` / `false` で書きます。

## 設定項目の意味

| 項目 | 必須・初期値 | 意味 |
| --- | --- | --- |
| `title` | 必須 | 記事一覧と記事ページのタイトル。1〜50文字相当。 |
| `slug` | 必須 | 記事を識別する値。1〜100文字相当。`my-first-post` ならURLは `/posts/my-first-post`。 |
| `created_at` | 静的公開では指定する | 公開日時。タイムゾーン付きの形式を推奨。未来の日時の記事は、その時点では公開されません。 |
| `excerpt` | 省略可 | 記事一覧の紹介文。指定する場合は1〜100文字相当。省略すると本文から抜粋を生成します。 |
| `tags` | 必須 | タグのリスト。付けない場合は `[]`。 |
| `categories` | 必須 | カテゴリのリスト。付けない場合は `[]`。 |
| `icatch_path` | 省略可 | サムネイル画像のパス。例：`"/image/example.png"`。指定する場合は1〜200文字相当。省略時はサイト設定の既定画像を使います。 |
| `table_of_contents` | 省略時 `false` | `true` で目次を表示、`false` で非表示。 |
| `deleted` | 省略時 `false` | `true` にしてseedすると、そのslugの記事をデータベースから削除します。 |

文字数の上限はUTF-16単位です。絵文字などは1文字で2単位になる場合があります。

### タイトルとslug

タイトルはページ側で表示するので、本文は導入文や `##` から始められます。

URLを決めるのはファイル名ではなく `slug` です。ほかの記事と重複しない値を使ってください。同じslugでseedすると既存記事を更新します。

### 公開日と更新日

```yaml
created_at: "2026-09-22T12:00:00+09:00"
```

これは日本時間の正午です。`Z` はUTCを表します。タイムゾーンのない `"2026-09-22 12:00:00"` や日付だけの `"2026-09-22"` は日本時間として扱います。`date` も別名として使えますが、`created_at` とどちらか一方だけを書きます。

通常のseedでは、省略時に新規記事へ登録時刻が入り、既存記事は元の公開日を保持します。静的公開ではビルドごとに公開日が変わらないよう必ず明示してください。`RUST_BLOG_REQUIRE_CREATED_AT=1` を設定すると指定漏れをエラーにできます。

**`updated_at` はMarkdownで指定する設定ではありません。** 記事データの変更をseedで反映したときに自動設定されます。

未来の日時を指定した記事を静的サイトで公開するには、その日時以降に再度exportとデプロイが必要です。

### タグ・カテゴリ・目次

```yaml
tags: ["Rust", "SQLite"]
categories: ["開発"]
table_of_contents: true
```

タグ・カテゴリを付けない場合も項目自体は書き、値を `[]` にします。大文字・小文字は同一視され、`Rust` と `rust` は同じタグになります。

目次は見出しの階層に沿って表示されます。同名の見出しでも別々の場所にリンクします。コードブロック内の `#` は目次には入りません。

## 本文の主な書き方

### 見出し・段落・強調

```markdown
## 大きな見出し

最初の段落です。

空行を挟むと別の段落になります。

### 小さな見出し

#### さらに小さな見出し

**太字**、*斜体*、~~取り消し線~~

変数名や関数名は `value` や `main()` のように囲みます。
```

段落・見出し・リスト・コードブロックの前後には空行を入れます。段落内で明示的に改行する場合は、行末に半角スペースを2つ置きます。

### 箇条書き・手順

```markdown
- 項目A
- 項目B
  - 項目Bの補足

1. 最初の手順
2. 次の手順

- [ ] 未完了
- [x] 完了
```

### リンク・画像

```markdown
[リンクの名前](https://example.com)

[このブログの記事](/posts/31)

![画像の説明](/image/example.png)
```

画像は通常 `content/image/` に置き、本文では `/image/` からのパスを書きます。画像名は実際に配置したファイル名に置き換えてください。画像の説明は読み込めない場合やスクリーンリーダーで使う代替テキストです。

### コードブロック

バッククォート3つで囲み、開始側に言語名を付けます。

````markdown
```rust
fn main() {
    println!("Hello, world!");
}
```

```bash
cargo run
```
````

`rust`、`kotlin`、`java`、`javascript`、`python`、`cpp`、`csharp`、`bash`、`json`、`yaml` などに対応します。色分けは整形ではないので、インデントは自分で揃えます。実行ログなどは `text` を指定できます。

### 引用・表・脚注

```markdown
> 引用する文章です。
>
> 引用の中でも段落を分けられます。

| 項目 | 説明 |
| --- | --- |
| Rust | プログラミング言語 |
| SQLite | データベース |

本文に補足を付けます。[^note]

[^note]: 補足の内容です。
```

表のセル内で `|` 自体を書きたい場合は `\|` と書きます。幅の広い表は横にスクロールできます。

## 固定ページの場合

このAboutページのような固定ページは `content/fixed_contents/` に置きます。固定ページで使える設定は `title`、`slug`、`excerpt` の3つです。`title` と `slug` は必須、`excerpt` は省略できます。

```yaml
---
title: "このブログについて"
slug: "about"
excerpt: "ブログの紹介ページです。"
---
```

記事用の `created_at`、`tags`、`categories`、`icatch_path`、`table_of_contents`、`deleted` は固定ページの設定としては使えません。本文のMarkdown構文は記事と共通です。

## 編集を反映する

Markdownを編集したらseedでデータベースへ反映します。静的サイトではexportして生成物をデプロイします。

開発用Docker環境では次のコマンドを使います。

```bash
docker compose exec web cargo run -p rust_blog --bin seed
docker compose exec web cargo run -p rust_blog --bin export
```

ファイルを削除しただけでは、既存データベースの記事は消えません。取り下げる場合は `deleted: true` でseedし、静的サイトも再生成してください。
