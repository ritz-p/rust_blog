# Lists with Multiple Blocks

1. **コードを含む項目**です。

    項目内の二つ目の段落です。次のコードも同じ項目の中に表示されます。

    ```rust
    fn main() {
        println!("Hello from a list!");
    }
    ```

    コードの後も同じ項目の文章が続きます。

2. **引用を含む項目**です。

    > 引用の最初の段落です。
    >
    > - 引用内の箇条書き
    > - **太字**と `inline_code()` のある項目
    >
    > 引用内の最後の段落です。

    引用の後も番号付きリストの字下げが保たれることを確認します。

3. **画像を含む項目**です。

    ![Rust mascot inside a list](/image/rustacean-orig-noshadow.png)

    画像の下の説明文です。

    - 子の項目
        - 孫の項目と[外部リンク](https://www.rust-lang.org/)
        - 次の孫の項目
    - 二つ目の子の項目

4. **表を含む項目**です。

    | Item | Value |
    | :--- | ---: |
    | First | 1 |
    | Second | 2 |

    表の後の文章も同じ項目に含まれます。

# Quotes with Code

> ## Heading Inside a Quote
>
> 引用内の見出しとコードの余白を確認します。
>
> ```javascript
> function greet(name) {
>     return `Hello, ${name}`;
> }
> ```
>
> 引用内のコードの後の文章です。
