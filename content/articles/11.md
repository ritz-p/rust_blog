# Whitespace and Special Characters

タブによる字下げ、空行、日本語コメント、HTML に使われる文字がそのまま表示されることを確認します。

```rust
fn main() {
	// 日本語コメントとタブによる字下げ
	let html = "<span>hello & goodbye</span>";

	println!("{}", html);
}
```
