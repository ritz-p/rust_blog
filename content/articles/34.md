## クラスとブロック

```ruby
class Greeting
  def initialize(name)
    @name = name
  end

  def message
    "Hello, #{@name} <tag> & value"
  end
end

options = { enabled: true, count: 3 }
%w[世界 Ruby].each do |name|
  puts Greeting.new(name).message if options[:enabled]
end
```
