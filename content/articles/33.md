## クロージャと文字列補間

```groovy
def names = ['世界', 'Groovy']
def settings = [enabled: true, retries: 3]
def pattern = ~/G\w+/

names.each { name ->
    println "Hello, ${name}: ${settings.retries}"
    if (name ==~ pattern) {
        println 'matched <tag> & value'
    }
}
```
