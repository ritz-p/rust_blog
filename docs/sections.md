# 記事区分とタブ

`blog_config.toml` の `[navigation]` と `[[navigation.tabs]]` で表示順とタブを設定します。設定例はリポジトリの同ファイルを参照してください。

- `kind = "all"` は全区分の記事を表示します。固定ページは含みません。IDは `all` 固定で、1つ必要です。
- `kind = "section"` はその区分の記事一覧です。
- `kind = "page"` は `slug` で指定した固定ページを表示します。
- `home` はトップに表示するタブのIDです。省略時は `all` です。
- `default_section` は記事の所属を省略した場合の区分です。

タブは全種類合わせて最大10個です。IDは小文字の英数字・ハイフン・アンダースコアを使い、重複できません。`label` は表示名です。

記事のYAMLフロントマターに `section: blog` のように所属を1つ指定します。固定ページや `all` のIDは指定できません。変更後はseedを実行します。既存DBには先にmigrationを適用してください。既存記事の所属は `blog` になります。

カテゴリ・タグは所属区分内で独立します。同じ名前でも区分が異なれば別の項目となり、絞り込み結果も混ざりません。区分一覧にはその区分で使用中の項目だけを表示し、「すべて」では全区分の項目を表示します。`blog` 以外の項目は `[区分ID] 名前` と表示して区別します。既存の `blog` のURLは維持します。区分の識別に使うため、`blog` のカテゴリ・タグ名の先頭の `[` は予約されています。

サーバーのURLは `/all`、`/sections/<ID>` で、ページ番号は `?page=2` です。静的出力は `/all/`、`/sections/<ID>/`、その下の `page/2/` です。サーバーのトップは選択したタブへリダイレクトし、静的出力のトップには選択したタブのページを配置します。既定の全記事トップでは従来の検索・月別アーカイブも利用できます。

seedも `RUST_BLOG_CONFIG_PATH`（既定 `blog_config.toml`）から区分設定を読みます。exportと同じ設定を指定してください。DBからMarkdownを書き出す場合も所属と元のカテゴリ・タグ名を保持します。
