# 記事区分とタブ

`blog_config.toml` の `[navigation]` と `[[navigation.tabs]]` でタブを設定します。全記事タブは常に先頭に表示し、残りのタブは設定に書いた順に並びます。設定例はリポジトリの同ファイルを参照してください。

- `kind = "all"` は全区分の記事を表示します。固定ページは含みません。IDは `all` 固定で、1つ必要です。
- `kind = "section"` はその区分の記事一覧です。
- `kind = "page"` は `slug` で指定した固定ページを表示します。
- `home` はトップに表示するタブのIDです。省略時は `all` です。
- `default_section` は記事の所属を省略した場合の区分です。

タブは全種類合わせて最大10個です。IDは小文字の英数字・ハイフン・アンダースコアを使い、重複できません。`label` は表示名です。

記事のYAMLフロントマターに `section: blog` のように所属を1つ指定します。固定ページや `all` のIDは指定できません。変更後はseedを実行します。既存DBには先にmigrationを適用してください。既存記事の所属は `blog` になります。

カテゴリ・タグは所属区分内で独立します。同じ名前でも区分が異なれば別の項目となり、絞り込み結果も混ざりません。カテゴリ・タグの一覧はヘッダーの Categories と Tags から開けます。`blog` 以外の項目は `[区分ID] 名前` と表示して区別します。既存の `blog` のURLは維持します。区分の識別に使うため、`blog` のカテゴリ・タグ名の先頭の `[` は予約されています。

サーバーのURLは `/all`、`/sections/<ID>` で、ページ番号は `?page=2` です。静的出力は `/all/`、`/sections/<ID>/`、その下の `page/2/` です。サーバーのトップは選択したタブへリダイレクトし、静的出力のトップには選択したタブのページを配置します。検索はトップ設定に依存しない `/search`（静的出力は `/search/`）で利用でき、月別アーカイブの検索フォームもこのURLへ送信します。

記事タブの「時期別」には、そのタブに掲載時刻を迎えた記事がある年月を `[common].timezone` 基準で表示します（既定は UTC）。年月を選ぶとタブ内で絞り込まれ、「すべて」を選ぶと同じタブの全期間に戻ります。

seedも `RUST_BLOG_CONFIG_PATH`（既定 `blog_config.toml`）から区分設定を読みます。exportと同じ設定を指定してください。DBからMarkdownを書き出す場合も所属と元のカテゴリ・タグ名を保持します。
